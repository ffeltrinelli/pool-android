# Third-party software

Apache Commons Math 3.6.1 (`org.apache.commons:commons-math3:3.6.1`) provides CMA-ES (Covariance Matrix Adaptation Evolution Strategy), an optimizer that improves shot direction and power by evaluating batches of variations.

Source and project documentation: https://commons.apache.org/proper/commons-math/

`Apache-2.0.txt` and `commons-math3-NOTICE.txt` are copied unchanged from the dependency JAR’s `META-INF/LICENSE.txt` and `META-INF/NOTICE.txt`. These files are bundled with both Android and desktop assets. The library is used without source modifications.

Lato Regular supplies the splash and gameplay UI. Its source, copyright, and bundled SIL Open Font License are documented in [font credits](../fonts/README.md).
